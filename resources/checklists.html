Checklists

Reusable lists for release testing and regression.

Smoke test

  • App launches and the main screen loads.
  • Sign in and sign out work.
  • The primary flow completes end to end.

Release sign-off

  • No open blocker or critical bugs.
  • Regression suite passed on the target builds.
  • Release notes reviewed.

Accessibility pass

  • Everything is reachable with the keyboard or a screen reader.
  • Text scales without clipping.
  • Color contrast meets WCAG AA.
