Screenshots and screen recording

A short video is often the fastest way to explain a bug. How to capture the screen on every platform, and how to mirror a phone live on your computer.

Quick reference

Platform Screenshot Screen recording
iPhone / iPad Side button + Volume up Control Center → Screen Recording
iOS Simulator Cmd+S Cmd+R
Android Power + Volume down Quick Settings → Screen record
macOS Cmd+Shift+3 / 4 Cmd+Shift+5
Windows Win+Shift+S Snipping Tool → Record
Linux (GNOME) Print Screen Print Screen → video toggle
ChromeOS Ctrl + Show windows Quick Settings → Screen capture

iOS

On the device

  • Screenshot: press the side button and Volume up together. On iPhones with a Home button, press Home and the side button.
  • Recording: open Control Center and tap Screen Recording. If it isn't there, add it from the Control Center edit mode (or Settings → Control Center on older iOS).
  • Long-press the Screen Recording button to turn the microphone on or off.
  • Tap the red indicator at the top of the screen to stop. The video goes to Photos.

Mirror live with QuickTime

QuickTime Player on a Mac can show an iPhone or iPad screen live over a cable. Use it to demo a bug in a call, or to record in better quality without filling the phone.

  1. Connect the device to the Mac with a cable, unlock it and tap Trust if asked.
  2. Open QuickTime Player and choose File → New Movie Recording.
  3. Click the arrow next to the record button and choose the device under Camera. Choose it under Microphone too, to get the app's sound.
  4. The device screen appears live. Click record to save it as a video.
Clean status barWhile recording, iOS usually shows a tidy status bar with full battery and signal, which is nice for screenshots and demos.

From Xcode and the Simulator

  • Real device: Window → Devices and Simulators, select the device, then Take Screenshot.
  • Simulator: File → Save Screen (Cmd+S) and File → Record Screen (Cmd+R). Files are saved to the Desktop. 
# Screenshot of the booted simulator
xcrun simctl io booted screenshot screen.png

# Record video, press Ctrl+C to stop
xcrun simctl io booted recordVideo bug.mov

Android

On the device

  • Screenshot: press Power and Volume down together.
  • Recording: swipe down twice to open Quick Settings and tap Screen record (Screen recorder on Samsung). Available from Android 11.
  • Turn on Show taps in Developer options, so the video shows where you tapped.

With ADB

# Screenshot straight to your computer
adb exec-out screencap -p > screen.png

# Record video (stops after 3 minutes, or press Ctrl+C)
adb shell screenrecord /sdcard/bug.mp4
adb pull /sdcard/bug.mp4

Setting up ADB is covered in Platform tools & ADB. In the emulator, use the camera button in the side toolbar, or Extended controls → Record and Playback. See Emulators.

Mirror live with scrcpy

scrcpy is a free, open source tool that shows and controls an Android device from your computer, on macOS, Windows and Linux. You can type with your keyboard, click with the mouse and record at the same time.

  1. Turn on USB debugging on the device and connect it with a cable.
  2. Install scrcpy. On a Mac with Homebrew:
brew install scrcpy
brew install --cask android-platform-tools
  1. Run it. The device screen opens in a window.
# Mirror the screen
scrcpy

# Mirror and record to a file
scrcpy --record=bug.mp4

# Show taps, keep the device awake, smaller window
scrcpy --show-touches --stay-awake --max-size=1024
Audioscrcpy also forwards the device sound on Android 11 and later, so recordings include it.

macOS

  • Cmd+Shift+3: the whole screen.
  • Cmd+Shift+4: drag to select an area. Press Space to capture a window.
  • Cmd+Shift+5: toolbar to record the whole screen or a selected area. Options lets you turn on the microphone and show mouse clicks.
  • QuickTime Player → File → New Screen Recording does the same.

Windows

  • Win+Shift+S: Snipping Tool, to capture an area, window or the full screen.
  • PrtScn: the full screen, to the clipboard or Snipping Tool.
  • Recording: open Snipping Tool, switch to Record and select an area (Windows 11).
  • Win+Alt+R: Xbox Game Bar records the current app window, not the desktop.

Linux

  • GNOME: press Print Screen to open the screenshot tool. It switches between screenshot and screen recording.
  • KDE Plasma: Spectacle, also on Print Screen, takes screenshots and videos.
  • On any desktop, OBS Studio works for longer recordings.

ChromeOS

  • Ctrl + Show windows: the full screen.
  • Ctrl+Shift + Show windows: opens the screen capture tool.
  • Recording: Quick Settings → Screen capture, then switch to video. Files go to Downloads.

Browser

  • Chrome and Edge: open DevTools, press Cmd+Shift+P (or Ctrl+Shift+P) and run Capture full size screenshot for the whole page, or Capture node screenshot for one element.
  • Firefox: right-click the page and choose Take Screenshot.
  • Turn on the device toolbar in DevTools to capture the page at a phone screen size.

Tips for bug videos

  • Start recording a few seconds before the first step, and stop right after the bug.
  • Keep it short. One bug per video, ideally under a minute.
  • Show taps or clicks, so people can follow what you did.
  • Turn on Do Not Disturb, and hide personal data, real accounts and notifications.
  • If a file is too big for the bug tracker, compress it, for example with ffmpeg: 
ffmpeg -i bug.mov -vcodec libx264 -crf 28 bug.mp4

Attach the video to the last section of your bug report.
