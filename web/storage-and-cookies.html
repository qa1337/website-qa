Storage and cookies

Stale or corrupt browser data causes bugs that only appear for some users.

Inspect storage

Open DevTools and select the Application panel to view local storage, session storage, IndexedDB, and cookies.

Reset to a clean state

localStorage.clear();
sessionStorage.clear();

Cookie flags to check

  • Secure: sent only over HTTPS.
  • HttpOnly: not readable by scripts.
  • SameSite: controls cross-site sending.
