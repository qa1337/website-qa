Browser exception & error logs

Collect JavaScript exceptions and console errors from desktop and mobile browsers so developers can see what went wrong.

Other platforms: iOS crash & error logs · Android crash & error logs

Desktop browsers

  1. Open the developer tools: F12 or Ctrl+Shift+I on Windows and Linux, ⌘⌥I on Mac.
  2. Go to the Console tab and turn on Preserve log so reloads don't clear it.
  3. Reproduce the issue. Errors and exceptions show in red.
  4. Right-click the console and choose Save as… to export the log.
Safari on MacTurn on the developer tools first: Safari › Settings › Advanced › Show features for web developers (called Show Develop menu in menu bar in older versions).

If the error comes from a failed request, also export the network log. See Network debugging.

Chrome, Edge and Samsung Internet on Android

  1. Turn on USB debugging on the phone and connect it to your computer.
  2. On the computer, open Chrome and go to chrome://inspect/#devices.
  3. Find the phone's tab in the list and click inspect.
  4. Use the Console tab as you would on desktop.

Firefox on Android

  1. On the phone, open Firefox Settings and turn on Remote debugging via USB.
  2. On the computer, open Firefox and go to about:debugging#/setup.
  3. Click Enable USB Devices if shown, then connect to the phone.
  4. Select the tab you want and click Inspect, then open the Console tab.

Safari on iPhone and iPad

  1. On the device, open Settings › Apps › Safari › Advanced (or Settings › Safari › Advanced on older iOS) and turn on Web Inspector.
  2. Connect the device to a Mac and open Safari on the Mac.
  3. In the Develop menu, choose the device and then the page you want to inspect.
  4. Use the Console tab as you would on desktop.

What to include in the report

  • Browser name and version, device and operating system.
  • The page URL, the date and time, and the steps to reproduce.
  • The exported console log, and the network log if requests failed.
  • How many users or devices had the problem, if you know.
