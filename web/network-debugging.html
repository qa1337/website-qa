Network debugging

Most web bugs show up as a failing or slow request.

Export a HAR file

  • Open DevTools and select the Network panel.
  • Enable Preserve log, then reproduce the problem.
  • Right-click the list and choose Save all as HAR with content.

Inspect the failing request

  • Status code and response body.
  • Request payload and headers.
  • Timing: waiting time versus download time.
Before you shareHAR files can contain cookies and tokens. Remove them before attaching a file to a ticket.
